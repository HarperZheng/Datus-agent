# 语义层白名单字段手册 - 福建（v3）· 导读

物理表命名约定：fne_paybook_full_high＝缴款书宽表，fne_treasury_transfer_new＝缴库宽表；两表均为宽表，手册中不单独用「宽表」指代其中一张。

### 一、术语定义

**收入（默认口径，广义收入）**：缴款资金完成划拨、到达资金归宿后的收入。专户/代收资金以划拨到账（fenterdate·专户代收口径）为锚，称专户代收收入；国库资金以缴库到账（fenterdate·国库口径）为锚，称国库收入。广义收入＝专户代收收入＋国库收入。问数中出现「收入」而未加限定词时，一律按本口径理解。

**收缴收入／执收收入／征收收入（显式口径，划拨前）**：缴款资金已到执收侧、尚未划拨或缴库的收入；以缴款到账（收缴口径）freceiveddate＝执收到账日期，作为收缴／执收／征收到账的时间锚。仅当问数明确说「收缴收入」「执收收入」「征收收入」时，按本口径理解。「已完成记账」按「到账即记账」理解：记账时间＝对应口径的到账时间（收缴口径 freceiveddate、专户代收/国库口径 fenterdate），不按清分日期过滤。

**判别**：以资金是否离开执收侧为界——已划拨／已缴库且到账＝收入（fenterdate）；仍在执收侧、以执收到账日期计＝收缴收入／执收收入／征收收入（freceiveddate）。

### 二、数据集全景：三个数据集怎么分工

**关键分工**：收缴清分在缴款书宽表 fne_paybook_full_high；
资金收入按去向拆两个数据集、分别查询：专户/代收部分在缴款书宽表 fne_paybook_full_high（行段过滤），国库部分在缴库宽表 fne_treasury_transfer_new（全量）；两表之间不做联表、不回填，只声明三键对齐关系。

数据集一：收缴清分

**物理来源**：缴款书宽表 fne_paybook_full_high 全量（fbgtstyle 1/2/3 全取）。

**行粒度**：一行 = 一条清分明细（缴款书明细 × 分入方及分入金额）。

**回答的问题**：收了多少、清分给了谁。

**包含对象**：缴款书、缴款明细、清分记录、清分明细。

**去重规则：缴款书明细行**：行键 (fpaycode, fid)；票面金额 famt 随清分明细行重复携带，求和须按行键去重。

**去重规则：清分明细行**：行键 (fpaycode, fid, fcollectid)；fimamt 为行级原子金额，SUM(fimamt) 直接加总、不需要去重。

**关联数据集：国库收入**：关联条件：收缴清分中 fbgtstyle='1' 的行（资金去向为国库）与国库收入关联，关联键 (ftreasuryno, frecrgncode, fsubcode) = (ftransno,frecrgncode, fsubcode) 。关联用途：将国库收入数据集中的缴库侧事实（缴库日期、入库到账日期、缴库状态、收款国库）关联到收缴清分数据集，用于在项目、单位、资金性质、收入类别等收缴侧维度下查询国库缴库情况。

数据集二：专户/代收资金收入

**物理来源**：缴款书宽表 fne_paybook_full_high 行段：fbgtstyle IN ('2','3') AND fisclear='1'。字段全部原生，无回填。

**行粒度**：一行 = 一条清分明细（缴款书明细 × 分入方及分入金额），与收缴清分数据集行粒度相同。

**回答的问题**：专户/代收资金清分后划到哪、是否到账（收入口径即划拨口径）。

**包含对象**：专户收入、代收收入（划拨明细行）。

**去重规则**：行键 (fpaycode, fid, fcollectid)；fimamt 为行级原子金额，SUM(fimamt) 直接加总、不需要去重；本数据集唯一收入度量就是 fimamt（famt/ftotalamt/ftransamt 不进）。

数据集三：国库收入

**物理来源**：缴库宽表 fne_treasury_transfer_new 全量；不做联表、不回填，标准数据源。

**行粒度**：一行 = 一条缴库拆分行（缴库凭证 × 分入区划 × 缴库科目的一笔独立金额）；行键 (ftransno, forder) ≡ (ftransno, frecrgncode, fsubcode)，三键全局唯一。

**回答的问题**：国库资金缴到哪个国库、何时划库/入库、缴库状态如何；缴库口径的国库收入统计（全时段历史月份）。

**包含对象**：国库收入（缴库拆分行）。

**去重规则**：行键 (ftransno, forder)；famt 为行级原子金额，SUM(famt) 直接加总、不需要去重；famt（缴库拆分行粒度）与 fimamt（清分明细行粒度）是两种粒度的两种度量，不得混加，跨粒度核对只能经三键组级对账（Σfimamt(组) = famt）。

### 三、数据集对齐规则

**规则1｜字段原名直通**：各数据集字段全部保持宽表原名直通，字段清单见白名单工作表。

**规则2｜金额约束**：收缴清分和专户代收的收入度量 = fimamt（清分明细金额，行级直加）；国库收入度量 = famt（缴库拆分行金额，行级直加）；两种粒度两种度量，不得混加。

**规则3｜不回填、不补空**：三个数据集各自封闭：不跨表补 ''/NULL、不补值；维度缺失经关联键跨集取数（声明式），不落表。

**规则4｜关联规则（收缴清分 vs 国库收入）**：收缴清分与国库收入按三键关联：(ftreasuryno, frecrgncode, fsubcode) = (ftransno, frecrgncode,fsubcode)，many_to_many。基数分两级：行级多对一——组内 N 行清分明细对 1条缴库行；组级一对一——一个收缴清分三键组对应一个国库收入三键组。组内 Σfimamt = famt；跨集取数两侧各自聚合后按配对列合并对账。收缴清分与国库收入经三键对齐做关联查询时，金额度量一律使用收缴清分侧 fimamt——行级原子金额，SUM(fimamt)行级直加。

### 四、三个数据集的 Relationship（事实对齐）

**1. 收缴清分vs专户/代收资金收入：行级子集（同源同键）**：专户/代收资金收入 是 收缴清分的子集，行键统一 (fpaycode, fid, fcollectid)，每一行即收缴清分的同一物理行；跨集对齐 = 行键相等，无需 JOIN。

**2. 收缴清分vs国库收入：三键对齐**：对齐键 (ftreasuryno, frecrgncode, fsubcode) = (ftransno, frecrgncode, fsubcode)；基数分两级：组级一对一，行级多对一，组内 Σfimamt = famt（跨粒度对账恒等式）。
收缴侧维度（项目、单位、资金性质、收入类别）只在收缴清分侧，缴库侧事实（收款国库、划库/入库日期、缴库状态、预算级次、征收机关）只在国库收入侧；对齐组内可含多个项目，缴库行 famt不按项目拆分，项目粒度金额以收缴清分侧 SUM(fimamt) 为准。

**3. 业务时间线**：同一笔资金：缴款（收缴清分：收了多少、分给谁）→ 清分完成 → 去向二选一：专户/代收划拨（专户/代收资金收入：划到哪、到账没有）或 缴库（国库收入：缴到哪个国库、何时划库/入库）。

**4. 金额口径与守恒**：全口径收入（专户+代收+国库，缴款覆盖月份）= SUM(专户/代收.fimamt) + SUM(收缴清分·国库行.fimamt)；国库收入 famt用于组级查询，不与 fimamt 直接相加，不作为联合查询的金额度量。收缴清分与国库收入经三键对齐做关联查询时，金额度量一律使用收缴清分侧 fimamt——行级原子金额，SUM(fimamt)行级直加，可直接与项目、单位、资金性质、收入类别等收缴侧维度组合。收入时间轴则取国库收入侧的缴库时间（划库日期）、ftransdate、入库到账日期 fenterdate。

### 五、指标设计规则

两种类型

**时期型指标**：以「日期字段落在统计区间」为行集条件，统计该日期所标记业务事件的金额或笔数。

**状态快照型指标**：以「状态标志位取指定值」为行集条件，统计查询时点处于该状态的业务对象的金额或张数。

**判别**：换统计区间行集随之变＝时期型；换区间行集不变、换查询时点才变＝状态快照型（不可回溯，无同比）。

通用规则

**规则1｜五要素同表**：度量、行集条件、固化取值、时间锚、分组维度五个要素必须全部落在同一数据集内；任一要素跨数据集，单条指标不产，只能推理时手写 SQL。

**规则2｜粒度与去重**：统计值必须随粒度固化唯一去重键；不同粒度的度量是不同统计对象，不得混加、不得互加。

**规则3｜时间锚即口径**：一条指标只绑一个时间锚，锚点不同即口径不同；未加限定词的问法按术语定义落默认锚。

**规则4｜谓词书写**：「未达态」用否定式（不等于目标值），空值天然落入、不另写空值标注；「已达态」用等值正写；互为镜像的两个状态字段只取其一，不设重复判据。

**规则5｜快照切片互斥**：状态快照型指标的切片必须是对同一数据集的互斥切分——各切片谓词不得有交集，任一行至多落入一个切片，谓词间有包含关系的必须在定义中显式排除对方；满足后切片相加即各状态存量合计、无重复计。

**规则6｜同比**：只挂时期型（快照型不可回溯）；衍生同比只挂基础指标，带固化过滤的成员不单设、由基准同比叠加过滤承载；每条主时间锚至多配一条预设同比；跨段合成的总口径不单设，由各段同比分承。

**规则7｜近义词分界**：近义词按口径族分配，关键限定词只属一族，防止不同口径的路由互串。例外——双答制：一个词同时对应两个互补指标时，两个结果并列返回、各自标注口径与粒度，不相加、不单选。首例：已收缴 → 执收到账金额（到账口径）＋ 缴款书已缴未到账金额。
