# 非税问数：业务场景与查询需求梳理

## 一、 基础知识
*   **管理架构**：一个区划下有多个主管部门，一个主管部门下有多个执收单位/收入单位，一个执收单位可执收多个收费项目。
*   **数据层级**：资金性质 > 预算科目 > 收费项目。每个收费项目有对应的预算科目、资金性质、收入类别。

## 二、 收入查询 

关键字：清分收入、实际收入、实收、划拨收入、汇总收入。

### 1. 收入要素
*   **基础字段**：收入日期（到账日期）、记账日期（到账日期，按口径取 fenterdate/freceiveddate）、清分日期（可入库日期，fcleardate）、执收区划、收入区划、执收单位、收入单位（记账单位）、预算单位、收费项目、收入类别、资金性质、收入科目（预算科目为其别名）、缴款日期、缴款码、业务类型（直接汇缴）、项目收入金额（缴款书项目金额）、项目收入金额(本级)。
*   **类别字段**详细说明：
    *   资金管理方式（fbgtstyle）：国库、专户、代收、其他。
    *   是否纳入预算：纳入预算管理资金、财政专户管理资金：
        *   纳入预算管理资金：
            - 一般公共预算收入 -> 国库资金
            - 政府性基金预算收入 -> 国库资金
            - 国有资本经营预算收入 -> 国库资金
            - 社会保险基金预算资金 -> 专户资金
        *   财政专户管理资金（教育收费：高中以上学费） -> 专户资金
    *   收入类别：政府性基金收入、专项收入、行政事业性收费收入、罚没收入、国有资本经营收入、国有资源(资产)有偿使用收入、捐赠收入、政府住房基金收入、其他收入(代收资金、代管资金、其他的)。

### 2. 统计值
*   **项目收入金额(本级)**：按全口径收入恒等式计算——全口径收入 ＝ SUM(专户/代收·fimamt) ＋ SUM(收缴清分·国库行·fimamt)，不含退付；"本级"（本单位/本区划等）按实际问数问题落到对应维度过滤。

### 3. 应用场景
#### ① 财政用户
*   **查询各单位的收入情况**：
    *   按单位查看本月收入情况 -> 统计维度：收入日期=本月，按“收入单位”汇总收入金额
    *   按单位项目查看本月收入情况 -> 统计维度：收入日期=本月，按“收入单位+收费项目”分项汇总收入金额
    *   按单位科目查看本月收入情况 -> 统计维度：收入日期=本月，按“收入单位+预算科目”分项汇总收入金额
    *   按单位收入类别查看本月收入情况 -> 统计维度：收入日期=本月，按“收入单位+收入类别”分项汇总收入金额
*   **查询各科目的收入情况**：
    *   根据时间范围（收入日期），按预算科目\预算科目+收入区划\预算科目+收入单位\预算科目+预算单位\预算科目+收费项目分项汇总收入金额
    *   *举例：XXX预算单位本月各科目收入情况 -> 收入日期=本月，预算单位=XXX预算单位，按预算科目分项汇总收入金额*
*   **查询各项目的收入情况**：根据时间范围（收入日期），按收费项目\收费项目+收入区划\收费项目+收入单位\收费项目+预算单位\收费项目+预算科目分项汇总收入金额
*   **查询各资金性质收入情况**：根据时间范围（收入日期），按照资金性质\资金性质+收入区划\资金性质+收入单位\资金性质+预算单位\资金性质+预算科目\资金性质+收费项目分项汇总收入金额
*   **查询各收入类别情况**：根据时间范围（收入日期），按照收入类别\收入类别+收入区划\收入类别+收入单位\收入类别+预算单位\收入类别+预算科目\收入类别+收费项目分项汇总收入金额
*   **查询各级区划收入情况**：根据时间范围（收入日期），按照收入区划+主管部门+收入单位+资金性质+预算科目+收费项目分项汇总收入金额
*   **查询其他区划分入本区划的收入情况**：根据时间范围（收入日期），条件“收入区划≠本区划”且“执收区划=本区划”，可按执收区划分项统计收入金额
*   **查询本区划分到其他区划的收入情况**：根据时间范围（收入日期），条件“执收区划=本区划”且“收入区划≠本区划”，按收入区划统计收入金额
*   **查询本区划已完成记账的收入情况**：根据时间范围（到账日期，按口径取 fenterdate），条件“收入区划=本区划”，可按执收单位分项统计收入金额

#### ② 单位用户
*   **查询本单位收入情况**：
    *   分入本级国库收入 -> 根据时间范围（收入日期），条件“执收单位=本单位”且“收入区划=本区划”且“资金性质=一般公共预算收入\政府性基金预算收入\国有资本经营预算收入”，可按资金性质分项统计收入金额
    *   分入本级专户收入 -> 根据时间范围（收入日期），条件“执收单位=本单位”且“收入区划=本区划”且“资金性质=财政专户管理资金\社会保险基金预算资金”，可按资金性质分项统计收入金额
    *   分入各级区划收入 -> 根据时间范围（收入日期），条件“执收单位=本单位”，可按收入区划分项统计收入金额
*   **查询其他单位分入本单位的收入情况**：根据时间范围（收入日期），条件“收入单位=本单位”且“执收单位≠本单位”，可按执收单位分项统计收入金额
*   **查询本单位分入其他单位的收入情况**：根据时间范围（收入日期），条件“执收单位=本单位”且“收入单位≠本单位”，可按收入单位分项统计收入金额
*   **查询本单位执收资金分入各级区划收入**：根据时间范围（收入日期），条件“执收单位=本单位”，按收入区划统计收入金额
*   **其他查询**：
    *   xxx缴款码收入是否形成收入 -> 条件“缴款码=xxx”是否进入专户/代收/国库的到账阶段，锚点为对应数据行的 fenterdate
    *   6月份之前已收缴的收入 -> 含混问法（"已收缴"未限定到账与否），并列返回两个结果，两数并列呈现、不加总：
    *   执收到账金额：到账日期在 6 月前的资金，明细粒度（缴款明细金额）
    *   缴款书已缴未到账金额：已缴款确认且资金未到账的存量，缴款书粒度（票面金额）
    *   上下文明确"到账"时只返回执收到账金额

## 三、 收缴查询

### 1. 收缴要素
*   **缴款书要素**：缴款码、业务类型（直接汇缴）、执收区划、执收单位、开票人、开票日期、金额合计（票面金额）、缴款有效期、缴款日期、缴款渠道、资金是否到账。
*   **缴款明细要素**：收费项目、收费标准、执收数量、执收金额（项目金额）、资金性质、收入科目、是否清分、清分日期。

### 2. 统计值
*   **笔数**：项目金额 -> 按项目统计，使用项目金额
*   **金额**：
    *   票面金额 -> 按照缴款书统计，使用票面金额

### 3. 应用场景
#### ① 财政用户
*   与去年对比整体征收（收缴）进度 -> 按月同比今年和去年每月收缴金额，依据缴款日期，根据执收区划\主管部门\执收单位\资金性质\预算科目\收费项目\单据或多维角度统计票面金额。

#### ② 单位用户
*   **本年共完成收费XXX笔** -> 条件“缴款日期在本年范围”且“执收单位=本单位”统计缴款书笔数，可按业务类型（直接汇缴）分项统计
*   **本年应缴未缴（未缴款销号）情况** -> 条件“开票日期在本年范围”且“执收单位=本单位”且“缴款日期为空（或缴款状态=未缴款）”且“缴款书有效期>系统当前日期（缴款书未过期）”且“缴款书未作废”统计缴款书张数和票面金额，可按业务类型（直接汇缴）分项统计
